# Security and Limitations
- No customer data, credentials, PHI or genuine audit evidence should be uploaded publicly.
- Synthetic SIM:// evidence references are not links to actual evidence.
- This project has no live Microsoft 365, Jira, Rapid7, SIEM, or Entra ID integrations.
- Metadata checks do not establish evidence authenticity or effectiveness.
- Ready for sample review is **not** an audit pass.
- No production controls, scans, incident response or remediation were performed.
- Neither PCI DSS nor SOC 2 compliance is determined.
