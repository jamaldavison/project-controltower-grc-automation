# Proposed ITGC Control Catalog

| Control | Example objective | Evidence proposal | Human test required |
|---|---|---|---|
| ITGC-AC-01–03 | Privileged access and recertification performed as designed | Access exports, approval tickets and reviewer sign-off | Validate population, access correctness and revocations |
| ITGC-CH-01–03 | Changes approved, tested and traceable | Tickets, change windows, approvals, commits | Trace deployed changes to approvals and tests |
| ITGC-VM-01–02 | Risk-ranked vulnerabilities addressed on policy schedule | Authenticated scans, exceptions, patch tickets | Validate scan coverage, criticality and remediation |
| ITGC-BA-01–02 | Restore tests support recoverability | Job logs, restore records and test evidence | Observe restore result and retention period |
| ITGC-IR-01–02 | Incidents triaged, documented and escalated | Incident records, timelines and lessons learned | Assess timeliness and procedural completeness |

These are fictional local control IDs, **not** official verbatim PCI DSS requirements. Regulatory mapping requires a separate scoping exercise.
